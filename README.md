# SshTunnelToolbox（SSH 隧道工具箱）

一个 Windows 下的 SSH 本地端口转发（`-L`）图形工具，底层调用 PuTTY 的 `plink.exe`。
适合需要长期保持若干条隧道（数据库、远程桌面、内网 SSH 等）的场景：多配置、自动重连、托盘常驻、开机自启。

## 功能

- 多个配置（每个配置一台 SSH 服务器 + 若干条 `-L` 端口转发），可新建 / 复制 / 重命名 / 删除
- 断线自动重连（可设重连间隔），托盘图标显示状态，右键可按配置启动 / 停止 / 重连
- 端口占用检查、本地端口连通性测试
- **跳板机**：勾选“通过跳板机连接”，相当于 `ssh -J 跳板用户@跳板机`
- **从 ssh 命令导入**：粘贴 `ssh -N -L ...` 命令自动填好配置
- **获取指纹**：一键读取服务器 / 跳板机的主机密钥指纹；主机指纹为空时，启动前会自动获取并保存（首次信任 TOFU）
- 密码使用 Windows DPAPI（当前用户）加密保存；plink ≥ 0.77 时通过临时 `-pwfile` 传递，连接成功后立即删除

## 运行环境

- Windows 7 SP1 / 10 / 11，.NET Framework 4.7.2 或更高（Windows 10 1803+ 自带）
- 已安装 [PuTTY](https://www.chiark.greenend.org.uk/~sgtatham/putty/)（需要其中的 `plink.exe`，建议 0.77 及以上）。
  程序会在 `C:\Program Files\PuTTY`、`C:\Program Files (x86)\PuTTY` 和 `PATH` 中查找，也可在“设置”里手动指定。
- 配置保存在 `%APPDATA%\SshTunnelToolbox\config.json`

## 用法示例

以下地址均为示例（`10.0.0.1` 为通用私网示例地址，`192.0.2.x` 为 RFC 5737 文档保留地址），请换成你自己的。

### 1. 普通本地转发（SSH 服务器本身就是“跳板”）

等价命令：

```
ssh -N -L 2222:192.0.2.20:22 user@10.0.0.1
```

- 主机：`10.0.0.1`，端口 `22`，用户名 `user`，填写密码
- 点“获取指纹”填入主机指纹
- 端口转发：本地地址 `127.0.0.1`，本地端口 `2222`，目标主机 `192.0.2.20`，目标端口 `22`

启动后访问本机 `127.0.0.1:2222` 就相当于从 `10.0.0.1` 去连 `192.0.2.20:22`。
**目标主机由 SSH 服务器去连接**，所以可以填只有 SSH 服务器才能访问的其它网段地址。

也可以直接点“从 ssh 命令导入…”，粘贴上面的命令。

### 2. 经跳板机登录另一台 SSH 服务器，再做转发

等价命令：

```
ssh -N -J jumpuser@10.0.0.1 -L 15432:192.0.2.30:5432 user@192.0.2.20
```

- 主机（勾选后显示为“SSH 主机”）：`192.0.2.20`，用户名 `user`
- 勾选“通过跳板机连接”，跳板机 `10.0.0.1`，跳板用户 `jumpuser`，填写跳板机密码
- 分别点两个“获取指纹”（获取 SSH 主机指纹时会自动经过跳板机）
- 端口转发：本地端口 `15432`，目标主机 `192.0.2.30`，目标端口 `5432`

实现方式：`plink -proxycmd "plink -nc 192.0.2.20:22 jumpuser@10.0.0.1" ... user@192.0.2.20`。

## 构建

需要 .NET SDK 6.0+（Windows / Linux / macOS 均可构建，引用程序集来自 NuGet 包 `Microsoft.NETFramework.ReferenceAssemblies`）：

```
dotnet build src/SshTunnelToolbox.csproj -c Release
```

输出：`src/bin/Release/net472/SshTunnelToolbox.exe`（单文件，无额外 DLL）。

## 注意事项

- plink 以 `-batch` 运行，不会弹出交互提示：未填写指纹且 PuTTY 未缓存该主机密钥时连接会失败，请先“获取指纹”。
- 私钥登录请使用 Pageant 加载 `.ppk` 私钥（不支持 `-i`）。
- 跳板模式下“SSH 主机”不能是 `localhost` / `127.x`（PuTTY 对本机地址不走代理）。
- 只支持一级跳板机；只支持本地转发 `-L`。
- 保存的密码只有同一 Windows 用户能解密，换用户 / 换电脑需重新输入。
